## 루트바이브는 무엇인가요

루트바이브는 **만들고 싶은 것을 평소 쓰는 말로 이야기하면 결과물까지 만들어 주는 맥 앱**이에요.
웹페이지, 문서, 발표 자료, 간단한 도구처럼 떠오른 아이디어를 대화로 설명하면, 루트바이브가
필요한 준비를 알아서 하고 만든 결과물을 화면 오른쪽에 차곡차곡 쌓아 줍니다.

쓰던 AI 계정(지금은 Claude)을 연결하는 것 말고는 따로 설정할 것이 없어요.

## 무엇이 좋은가요

- **개발 지식이 필요 없어요.** 개발 환경을 설치하거나 터미널에 명령어를 입력할 일이 없어요.
  하고 싶은 것을 말하면 필요한 준비는 루트바이브가 합니다.
- **도구를 고르지 않아도 돼요.** 문서 쓰기, 화면 그리기, 웹 확인 같은 도구가 앱 안에 이미
  들어 있고, 이야기에 맞춰 알아서 꺼내 씁니다. 쓰기 싫은 도구는 스위치로 끌 수 있어요.
- **모르는 사이에 무언가 해 버리지 않아요.** 파일을 만들거나 고치기 전, 명령을 실행하기 전에
  무엇을 할지 먼저 보여 주고 물어봅니다. 조심스럽게 쓰고 싶으면 「확인」 모드로 바꿀 수 있어요.
- **계속 지켜보지 않아도 돼요.** 사람이 정해야 할 것만 「확인할 것」에 모이고 나머지는 알아서
  진행돼요. 자리를 비웠다 돌아와도 무엇이 끝났고 무엇을 정해야 하는지 한눈에 보여요.
- **내 컴퓨터의 프로젝트 폴더로 바로 시작할 수 있어요.** 이미 있던 폴더를 골라 그 안에서
  작업을 이어 갈 수 있습니다.
- **무료예요.** 루트바이브 자체는 결제가 없어요. 연결한 AI 계정으로 동작합니다.
- **새 버전이 나오면 알려 줘요.** 앱을 켤 때 새 버전이 있으면 「업데이트 후 시작」 한 번으로
  최신 버전이 됩니다.

## 필요한 것

| | |
|---|---|
| 컴퓨터 | **Apple Silicon(M1 이상) Mac** — 인텔 칩 Mac에서는 실행되지 않아요 |
| AI 계정 | Claude 계정 |
| 운영체제 | macOS |

> 내 Mac이 Apple Silicon인지 확인하려면: 화면 왼쪽 위  메뉴 → **이 Mac에 관하여** →
> 「칩」 항목이 **Apple M1 · M2 · M3 · M4 …** 이면 사용할 수 있어요.
> 「프로세서: Intel …」 이면 아직 사용할 수 없어요.

Windows 버전은 준비 중이에요.

## 다운로드와 설치

### 1. 내려받기

아래 링크를 누르면 늘 최신 버전이 내려받아져요.

**👉 [RootVibe.dmg 내려받기](https://github.com/TOKTOKHAN-DEV/rootvibe/releases/latest/download/RootVibe.dmg)**

이전 버전이 필요하면 [Releases](https://github.com/TOKTOKHAN-DEV/rootvibe/releases)에서 고를 수 있어요.

### 2. 설치하기

1. 내려받은 **RootVibe.dmg**를 두 번 눌러 열어요.
2. 열린 창에서 **RootVibe** 아이콘을 **Applications** 폴더로 끌어다 놓아요.
3. 창을 닫고, Finder 왼쪽의 디스크 모양 옆 ⏏ 버튼을 눌러 꺼내요.

### 3. 처음 열기 — 「확인할 수 없는 개발자」가 뜰 때

루트바이브는 아직 Apple 공증을 받지 않아서, **처음 한 번** 아래 경고가 뜰 수 있어요.

> "RootVibe"은(는) Apple에서 악성 소프트웨어가 있는지 확인할 수 없기 때문에 열 수 없습니다.

이럴 때는 이렇게 열어 주세요.

1. 경고 창에서 **완료**(또는 취소)를 눌러 닫아요.
2.  메뉴 → **시스템 설정** → **개인정보 보호 및 보안**으로 가요.
3. 아래쪽 「보안」 부분에 `"RootVibe"이(가) 차단되었습니다` 옆의 **그래도 열기**를 눌러요.
4. Mac 암호(또는 Touch ID)를 입력하고, 다시 뜨는 창에서 **열기**를 눌러요.

이 과정은 처음 한 번만 하면 돼요. 그 뒤로는 평소처럼 Launchpad나 Applications에서 열면 됩니다.

### 4. 시작하기

1. 앱을 열면 **AI 계정 연결** 화면이 나와요. 쓰던 Claude 계정으로 로그인하세요.
2. 연결되면 입력창에 만들고 싶은 것을 평소 말로 적어 보내면 끝이에요.
   예: 「우리 가게 소개 페이지 만들어줘」
3. 이미 작업하던 폴더가 있다면 입력창 아래 📁 버튼으로 그 폴더를 골라 시작할 수 있어요.

## 업데이트

새 버전이 나오면 앱을 켤 때 **「업데이트 후 시작」 · 「다음에 업데이트」** 중에서 고르라고 물어요.
「업데이트 후 시작」을 누르면 받아서 설치한 뒤 바로 다시 켜져요. 따로 내려받을 필요가 없습니다.

오래된 버전은 일정 기간이 지나면 업데이트해야 계속 쓸 수 있어요. 그때는 앱이 먼저 알려 드려요.
